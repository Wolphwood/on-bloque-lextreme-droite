# On Bloque l'extrême droite
Un script à copier coller dans la console pour bloquer touts les comptes de l'extrêmes droites

⚠️ Ce script est purement à titre éducatif, étant une challenge personnel de savoir si c'était possible ou non.


### Comment l'utiliser ?
C'est simple, tu ouvre la console, tu copie colle, et en une vingtaines de minutes les 177 comptes seront bloqués.

### C'est dangereux ?
Demande à Chat GPT il te dira que potentiellement :

- Violation des CGU de X
- Risque de suspension de compte

---

A utiliser à vos risques et périles.
Il y à un delai aléatoire entre 3 et 8 secondes entre chaque ban
